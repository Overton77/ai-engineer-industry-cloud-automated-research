# Metric probes

Keep reach, adoption, endorsement, and durable contribution separate. Prefer canonical registries and transparent scholarly/community graphs. Licensed estimates are labeled estimates; Tavily and Firecrawl are discovery unless the underlying page is captured.

An observation records one canonical target, one versioned metric definition, observed and collected times, value or `unavailable_reason`, window/dimensions, visibility/access tier, measurement kind, estimate flag, immutable raw capture, locator, collector version, source policy version, quality flags, and provider provenance.

Prefer GitHub numeric IDs; purl plus ecosystem/name for libraries; DOI then arXiv/OpenReview for papers; YouTube video ID for recordings; and ROR/domain for organizations. Refuse a probe when identity resolution is ambiguous.
